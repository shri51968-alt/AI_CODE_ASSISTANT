# 💻 AI Code Assistant

An AI-powered Code Assistant developed as part of my Generative AI Internship at Skyrovix.

## 🎯 Project Overview

The AI Code Assistant helps users with programming tasks using Generative AI.

Users can select a programming language and choose whether they want to generate, explain, debug, or improve code. The AI provides a response based on the user's request.

The application also supports follow-up questions using conversation context, allowing users to continue working with the previously generated code or explanation.

## 🔄 Workflow

1. User selects a programming language.
2. User selects the required coding task.
3. User enters a programming question or code.
4. The application creates a structured prompt.
5. The prompt is sent to the AI model through the Hugging Face Inference API.
6. The AI generates a response.
7. The response is displayed to the user.
8. The conversation is stored as context.
9. The user can ask follow-up questions about the previous response.
10. The AI uses the previous context to generate the follow-up response.

## 🧠 Prompt Design

The prompt includes:

- Programming language
- Selected coding task
- User's question or code

The AI is instructed to provide accurate, readable and beginner-friendly programming assistance.

Different instructions are provided for:

- Code generation
- Code explanation
- Code debugging
- Code improvement
- Follow-up questions
